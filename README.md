# 統測英文歷屆試題庫

四技二專統一入學測驗共同科目「英文」的純靜態練習站。介面沿用 `tvet-guowen` 已驗證的年度複選、答題、錯題本、學習歷程、查題與教師出卷流程，資料與分類則重新依英文科官方原卷建置。

## 正式網站

- Cloudflare Pages：<https://tvet-english.pages.dev>
- Vercel：<https://tvet-english.vercel.app>
- Netlify：<https://tvet-english.netlify.app>

## 收錄範圍

- 90–115 學年度官方題本、公告答案與線上答案卡，共 26 年、1,196 題選擇題。
- 1,196 題均完成題幹、A–D 選項、官方答案、本站自編解析與兩層分類，可直接跨年度作答。
- 90–109 年由官方 PDF 產生；110–115 年優先採官方 DOCX，並用官方 PDF 補回空格與圖像頁。
- 第 93 年純掃描題本，以及第 106、107 年缺文字層頁面，另有逐頁人工校正與官方原卷頁圖。
- 115 年 7 組題組完整呈現；第 31–32、33–35 題必要圖表由官方 PDF 裁切。
- 115 年官方試題研討會的 42 題難度／鑑別度分組，以及 9 題明確公布的精確選項分布。
- 115 年另有 3 題非選擇題，保留在官方原卷，未混入單選自動計分。

## 資料原則

- 題本、答案與統計只採技專校院入學測驗中心官方資料。
- 題幹與選項順序照官方原卷，不重排、不用坊間重打版補洞；掃描頁 OCR 結果以官方頁圖人工覆核。
- 精確 P、D 值與選項比例只收錄官方研討會明確公布的題例；其餘只保存官方交叉表等級。
- 找不到的官方精確統計維持空白，不用答對率或答案反推選項分布。

## 本機執行

```sh
npm install
npm test
npm run serve
```

從官方來源重新產生答案與 90–115 年完整題庫：

```sh
npm run build:data
npm run build:questions:all
```

系統需有 `pdftotext`、`pdftoppm`、`tesseract`（`eng+chi_tra`）與 `pandoc`。產生器會逐年檢查題號、題數與官方答案；測試另驗證題組範圍、A–D 選項、分類、解析及圖片路徑，缺漏時直接失敗。

## 問題回報

- 練習頁與查題頁可直接回報單題問題，系統會自動附上題幹、選項、答案、解析與官方來源。
- Vercel API 需要設定 `TELEGRAM_BOT_TOKEN` 與 `TELEGRAM_REPORT_CHAT_ID`；機密資料不得寫入版控。
- Cloudflare Pages 與 Netlify 的表單會跨站送往 Vercel API。
