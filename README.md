# 統測英文歷屆試題庫

四技二專統一入學測驗共同科目「英文」的純靜態練習站。介面沿用 `tvet-guowen` 已驗證的年度複選、答題、錯題本、學習歷程、查題與教師出卷流程，資料與分類則重新依英文科官方原卷建置。

## 正式網站

- Cloudflare Pages：<https://tvet-english.pages.dev>
- Vercel：<https://tvet-english.vercel.app>
- Netlify：<https://tvet-english.netlify.app>

## 收錄範圍

- 90–115 學年度官方題本、公告答案與線上答案卡，共 26 年、1,196 題選擇題。
- 115 學年度 42 題選擇題完成題文、四個選項、官方答案、教師解析與兩層分類。
- 115 年 7 組題組完整呈現；第 31–32、33–35 題必要圖表由官方 PDF 裁切。
- 115 年官方試題研討會的 42 題難度／鑑別度分組，以及 9 題明確公布的精確選項分布。
- 115 年另有 3 題非選擇題，保留在官方原卷，未混入單選自動計分。

## 資料原則

- 題本、答案與統計只採技專校院入學測驗中心官方資料。
- 題幹與選項順序照官方原卷，不重排、不用坊間重打版補洞。
- 精確 P、D 值與選項比例只收錄官方研討會明確公布的題例；其餘只保存官方交叉表等級。
- 90–114 年尚未完成逐題題文與分類，不把答案卡完成度說成完整題庫。

## 本機執行

```sh
npm install
npm test
npm run serve
```

從官方來源重新產生答案與 115 年題庫：

```sh
npm run build:data
npm run build:questions:115
```

系統需有 `pdftotext` 與 `pandoc`。產生器會驗證每年度答案題數及 115 年 42 題結構，缺漏時直接失敗。
